# 派遣の3年ルール いつまで計算機（お試し版）

派遣で働く人が、同じ課で働けるのはいつまでかを数えるページです。

https://paz67416.github.io/haken-3nen/

## できること

- この課で働きはじめた日（今の派遣の開始日）から、抵触日（働けなくなる最初の日）と、最後に働ける日まであと何日かを出します
- 前にも同じ課で派遣で働いていたときは、前の派遣とのあいだの空白で、続いている扱いか数え直しかを判定します（3か月を超える空白で数え直し）
- この課に戻れるいちばん早い日（3か月を超える空白をあけた日）と、1年になる日の目安を出します
- 期間制限の対象外（無期雇用・60歳以上など）にチェックすると、そう表示します

入力した内容は、保存も送信もされません。登録もいりません。

## 完全版について

就業履歴を20件まで入れて課ごとに数える、就業条件明示書の日付と比べる、3年までの道のり、無期転換（5年ルール）の目安、印刷・カレンダー（.ics）・URLでの保存ができる完全版（有料）は、note「余白の実験室」の記事で案内しています。

https://note.com/chodo_lab/n/n7ae8849cbab5

## ご注意

- 派遣先の同じ課（組織単位）で、同じ人が派遣で働ける期間（個人単位の期間制限）の目安です。法律の助言ではありません
- 最終的には、就業条件明示書（派遣元が渡す書面）と派遣元で確かめてください。事業所単位の抵触日は、明示書の日付を見てください
